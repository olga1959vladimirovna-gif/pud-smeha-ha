# Пуд Смеха — дизайн и поведение

## Назначение
Тёплый русскоязычный сайт со сказкой, добрыми байками и маленькими играми для взрослых. Существующую композицию и голос автора сохраняем. Это контентный сайт, не административное приложение.

## Визуальный характер
Сказочный Мешочек — главный персонаж. Светлые переходы от медового к розовому, округлые карточки, свободные поля. Новые иллюстрации — маленькие акварельные виньетки с карандашным контуром. Не превращать каждую карточку в картинку.

## Токены
Канонический источник новых токенов: `src/style.css`, блок `:root`. Существующие scoped-стили сохранены.

| Токен CSS | Значение | Роль |
|---|---|---|
| --bag-paper | #fffbeb | Бумага |
| --bag-ink | #292524 | Основной текст |
| --bag-muted | #57534e | Второстепенный текст |
| --bag-honey | #92400e | Действия и ссылки |
| --bag-pink | #fce7f3 | Мягкий акцент |
| --bag-line | #f5d88e | Границы |

Шрифт: существующий системный sans-serif с поддержкой кириллицы. Новые заголовки 28–40 px, текст 16–18 px, интерлиньяж 1.65–1.8. Слева выравниваются длинные истории и формы; по центру — короткие приветствия и действия. Ширина длинного текста до 68ch.

## Изменения по согласованию с автором
Первый экран → кнопка быстрой улыбки и небольшая навигация → сказка и байки → компактные факты → остальные разделы → смехотерапия и сохранённая коллекция. Первые шесть карточек видимы; остальные открываются по кнопке. Нажатие раскрывает текст без модального окна.

## Поведение
- Все новые действия — настоящие кнопки, переходы — ссылки; заметный клавиатурный фокус.
- Коллекция и число полученных открыток сохраняются в браузере на этом устройстве. Недоступное/повреждённое хранилище не ломает игру; показываем честное сообщение.
- Открытку можно скачать в PNG. Ошибки генерации видны рядом, повторная попытка доступна.
- История отправляется автору на отбор через выбранный автором канал; сайт не сообщает об успешной доставке без подтверждения. Публикация вручную, только с согласием посетителя.
- Фактические карточки ссылаются на исследования; фантазии явно подписаны.
- Локаль ru, подписи и сообщения на русском. Иллюстрации имеют заданную геометрию и lazy loading.
- Уважаем prefers-reduced-motion; отключаем декоративную анимацию, плавную прокрутку и autoplay видео при этом предпочтении. Скроллбар остаётся видимым.

## Проверка
Сборка Vite; браузер: быстрый переход, раскрытие/сворачивание, обновление страницы с сохранением коллекции, повреждённое хранилище, загрузка PNG, валидация истории, клавиатура, узкий экран 390 px, reduced motion. Новые данные не публикуются автоматически.
