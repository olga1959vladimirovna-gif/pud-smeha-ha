# Почём пуд СМЕХА?

Самостоятельная версия сайта, перенесённого из Chatium. Сохраняет тексты, оформление и интерактивные разделы оригинала.

## Запуск

```sh
npm ci
npm run dev
```

## Сборка и публикация

```sh
npm run build
npm run preview
```

Vercel автоматически собирает проект из GitHub: команда `npm run build`, папка результата `dist`.

## Структура

- `src/components/` — перенесённые компоненты Vue в скомпилированном JavaScript, с обычными импортами Vue вместо загрузчика Chatium.
- `src/main.js` — запуск приложения и настройки видео.
- `public/media/` — локальные копии ролика и обложки.
- `tailwind.config.js` — настройка стилей.

Для изменения контента редактируйте соответствующий компонент в `src/components/`. Исходные `.vue` из редактора Chatium не входили в публичную страницу; здесь сохранён доступный клиентский код.

Встроенные аналитика, служебный контекст и загрузчик Chatium удалены. Видео, обложка, стили и иконки хранятся вместе с проектом; для работы сайта Chatium и Kinescope не требуются.

## Новые возможности

- Быстрый переход к смехотерапии с первого экрана.
- Компактные факты и симптомы: сначала шесть карточек, затем раскрытие.
- Исследования со ссылками и отдельно обозначенные фантазии НИИ Хихиканья.
- Коллекция открыток сохраняется в localStorage этого браузера. Если хранилище недоступно, сайт сообщает об этом; очистка данных браузера удалит коллекцию.
- Любую открытку из коллекции можно прочитать повторно и скачать в PNG.
- Три акварельные иллюстрации в `public/illustrations`; промпты — в `PROMPTS.md` рядом с изображениями.
- Учтены клавиатурный фокус и предпочтение уменьшенной анимации.

`npm test` проверяет сохранение, восстановление и обработку ошибок коллекции.
