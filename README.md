# Почём пуд СМЕХА?

Самостоятельная версия сайта, перенесённого из Chatium. Сохраняет тексты, оформление и интерактивные разделы оригинала.

## Запуск

```sh
npm ci
npm run dev
```

## Сборка и публикация

```sh
npm run build
npm run preview
```

Vercel автоматически собирает проект из GitHub: команда `npm run build`, папка результата `dist`.

## Структура

- `src/components/` — перенесённые компоненты Vue в скомпилированном JavaScript, с обычными импортами Vue вместо загрузчика Chatium.
- `src/main.js` — запуск приложения и настройки видео.
- `public/media/` — локальные копии ролика и обложки.
- `tailwind.config.js` — настройка стилей.

Для изменения контента редактируйте соответствующий компонент в `src/components/`. Исходные `.vue` из редактора Chatium не входили в публичную страницу; здесь сохранён доступный клиентский код.

Встроенные аналитика, служебный контекст и загрузчик Chatium удалены. Видео, обложка, стили и иконки хранятся вместе с проектом; для работы сайта Chatium и Kinescope не требуются.

## Новые возможности

- Быстрый переход к смехотерапии с первого экрана.
- Компактные факты и симптомы: сначала шесть карточек, затем раскрытие.
- Исследования со ссылками и отдельно обозначенные фантазии НИИ Хихиканья.
- Коллекция открыток сохраняется в localStorage этого браузера. Если хранилище недоступно, сайт сообщает об этом; очистка данных браузера удалит коллекцию.
- Любую открытку из коллекции можно прочитать повторно и скачать в PNG.
- Три акварельные иллюстрации в `public/illustrations`; промпты — в `PROMPTS.md` рядом с изображениями.
- Учтены клавиатурный фокус и предпочтение уменьшенной анимации.

`npm test` проверяет сохранение, восстановление и обработку ошибок коллекции.

## Байки посетителей и кабинет

Посетители отправляют заголовок, текст, необязательное имя и согласие через `bag-gateway` в Supabase. Все записи сначала pending. Публичный API читает только approved; вставка и модерация напрямую гостям запрещены. `/admin` использует одноразовую ссылку на почту владельца. Серверная проверка сопоставляет подтверждённый аккаунт и действующую сессию с приватным списком владельцев; email не хранится в этом репозитории.

`supabase/schema.sql` — схема для чистой базы, `supabase/verify-rls.sql` — транзакционная проверка политик с откатом тестовых данных. `supabase/functions/bag-gateway/index.ts` — развёрнутая функция приёма и запроса входа. Все её секреты берутся из встроенного окружения Supabase; в браузере только publishable key. Нельзя менять его на service_role.

Защита формы: серверная проверка размеров и согласия, скрытое поле против простых ботов, идемпотентность по UUID, атомарный общий предел 5 новых баек в минуту и 100 в сутки. IP-адреса приложение не сохраняет. Это базовые ограничения, не полноценная CAPTCHA; при большом спаме нужна отдельная защита. Записи не удаляются автоматически: отклонённые остаются в закрытой очереди. Комментарии пока не включены.

Настройка входа: Site URL `https://pud-smeha-ha.vercel.app`, разрешённый redirect `https://pud-smeha-ha.vercel.app/admin`. Встроенная доставка писем Supabase ограничена; если она недоступна, необходимо настроить SMTP в кабинете провайдера. Сессия админки хранится только в sessionStorage вкладки; при выходе очищается. При закрытии вкладки нужно войти заново.
