# Котёнок Пончик — мультсериал

Часть проекта «Почём пуд СМЕХА?».

- Платформа: Recraft
- Модель: Seedance 2.5
- Целевая длительность: 4–5 секунд
- Соотношение сторон: 9:16
- Стиль: смешная динамичная 3D-анимация без диалогов

Первый ролик «Котёнок и непослушный блинчик» удачно создан за 5 секунд по первоначальному промпту с параметром `duration_seconds: 15`. Оригинал на локальном компьютере находится в папке `03_Готовые_видео`, кадры-референсы — в `01_Персонажи_и_референсы`.

На GitHub сохраняем каталог и JSON-промпты. Видео и изображения не загружаем автоматически в публичный репозиторий.

## Продолжение

Блинчик-бумеранг; Пончик и непослушный клубок; Пончик и пузырь-парик; Пончик и прыгающая клубника.
