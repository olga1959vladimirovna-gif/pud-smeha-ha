# Канонический интерфейс

## Источники бизнес-правил
Текущий запрос автора: посетители читают и отправляют байки без регистрации; только автор одобряет публикацию. Имя необязательно. Комментарии не входят в этот выпуск. `supabase/schema.sql` реализует разрешения, ограничения и переходы состояний.

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |

Нет выбора строк, дат, select/listbox или массовых действий. Фильтры — обычные ссылки с aria-current, не ARIA tabs. Прокруткой владеет документ. Все длинные формы остаются естественной высоты.

## Потоки
- Отправка: явное согласие на публикацию; проверка полей при отправке; первая ошибка получает фокус; текст сохраняется при ошибке. Успех только после сохранения pending. Повтор запроса использует тот же UUID, пока текст не изменён.
- Вход: письмо Supabase; email вводится владельцем и не отображается посетителям. Доступ проверяет база, а не скрытая кнопка. Сессия только в sessionStorage вкладки; уход из кабинета очищает её.
- Очередь: фильтр и страница в URL, по 10 записей, свежие первыми. Переход к следующей странице только при наличии записей. Устаревшие ответы игнорируются.
- Редактирование: открыть запись → изменить текст → сохранить в том же статусе либо «В Мешочек» / «Оставить за кулисами». Публикация требует отдельного явного действия. Изменение статуса обратимо. Черновики редактирования не сохраняются в браузер.
- Конфликт версий: не перезаписывать чужое/старое изменение. Сохранить ввод и предложить перечитать запись. Сеть/401/403: показать причину, не удалять введённый текст, предложить повторный вход.
- Несохранённый ввод: защищать уход средствами beforeunload; внутри кабинета переходы закрывает нативный app-owned dialog с отменой по умолчанию. Один общий Dialog и Field для повторяющихся сценариев.
- Публичные истории: только approved, 6 за раз, «Ещё байки» добавляет следующую страницу. HTML посетителей всегда отображается текстом.

## Состояния
Все запросы имеют таймаут, загрузку, пустое состояние, ошибку и повтор. На время мутации кнопки отключены; успех ждёт сервера. Никаких фиктивных записей в настоящей очереди. Критичные ошибки остаются рядом с формой. Локаль ru-RU, время Europe/Moscow с подписью МСК. Недоступная база не мешает читать основную сказку.
